# Tamafarm

Tamafarm adalah proyek aplikasi web untuk katalog dan pemesanan lobster, dengan halaman pembeli serta panel pengelolaan usaha.

Repositori ini digunakan untuk memperlihatkan gambaran proyek. Kode sumber aplikasi disimpan secara terpisah dan tidak disertakan di sini. Repositori ini tidak berisi aplikasi yang dapat dijalankan.

## Fitur proyek

- Katalog produk dan detail lobster.
- Keranjang, checkout, serta pelacakan pesanan pembeli.
- Penawaran pesanan, pembayaran, dan informasi pengiriman.
- Konsultasi pembeli dengan pengelola.
- Panel produk, kategori, pelanggan, pesanan, serta laporan.
- Pembagian akses pelanggan, admin, dan pemilik.

## Teknologi

- Frontend: React, Vite, dan Tailwind CSS.
- Backend: Laravel dengan autentikasi Sanctum.

## Hak penggunaan

Proyek ini merupakan hasil pengerjaan pribadi. Publikasi deskripsi ini tidak memberikan izin untuk menggunakan, menyalin, mendistribusikan, atau mengumpulkan proyek sebagai tugas atas nama pihak lain. Penggunaan membutuhkan izin dari pemilik proyek.
